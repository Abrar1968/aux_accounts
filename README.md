# Auxtech Ops

Accrual accounting and Lead CRM for Auxtech — Laravel 12 · Inertia.js · Vue 3 · Tailwind CSS v4 · MySQL · Pusher.

Replaces the *Auxtech Accrual Accounting Master 2026* and *Automated daily lead sheet* workbooks while
reproducing every calculation (golden-tested against the workbook's statements).
